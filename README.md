# tradetip app

Phone front-end for the private `tradetip` repo. This repo holds only the app shell (no data, no keys):
it reads `signals.json` from the private repo's `signals` branch with a fine-grained token that you
paste into the app once. The token stays in your phone's browser storage.

Install: open the GitHub Pages URL on your phone, connect, then Share → Add to Home Screen.
